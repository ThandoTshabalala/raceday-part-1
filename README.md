
# RaceDay – Part 1: System Planning and Database Design

## Project Overview

RaceDay is an event management system designed to allow organisers to create and manage running events, while participants can register for events, manage their enrolments, and view race results.

This repository contains Part 1 of the RaceDay project completed for the programming module. It focuses on system planning, database design, API endpoint planning, and SQL Server database implementation.

**Project Type:** Academic Coursework    
**Part:** Part 1 – System Planning and Database Design

## Project Objectives

- Design the database structure and relationships for the RaceDay system.
- Plan the API endpoints required to support the system's functionality.
- Create SQL Server database tables, constraints, relationships, and sample data.
- Document and provide evidence of database implementation and testing.
